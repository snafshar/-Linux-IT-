# Linux System Monitor

A beginner-friendly Bash script for practicing Linux system inspection.

## Concepts

- `uname` and host information
- `uptime`
- `/proc/loadavg`
- `free`
- `df`
- `who`
- `ps`
- command substitution
- pipes and redirection
- command availability checks

## Usage

```bash
chmod +x system-monitor.sh
./system-monitor.sh
```
