# SysOps Toolkit Exercises

1. Add a `--help` flag to each script that accepts arguments.
2. Extend the log summary to count `CRITICAL` and `FATAL`.
3. Modify the disk report to accept a mount point and reject nonexistent paths.
4. Add an output-file option to the checksum manifest, avoiding accidental overwrite.
5. Extend the backup preview to show source size before printing the proposed command.
6. Make the test script fail if any script contains a Bash syntax error.
7. Compare `ps` output with `top` and explain snapshot versus live monitoring.

For every extension, document assumptions, failure cases, and an example invocation.
