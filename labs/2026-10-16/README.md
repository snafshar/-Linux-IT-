# Linux Operations Mini-Project

A hands-on collection for local Linux practice.

## Exercises
- `host_report.sh`: capture basic host facts.
- `memory_report.sh`: inspect memory and swap.
- `service_report.sh`: list failed services.
- `python_log_count.py`: summarize severity labels in a text log.
- `permissions_lab.md`: practise permissions in a temporary directory.

Use a VM or a machine you administer. Commands are intended for inspection; review scripts before adapting them to production.
